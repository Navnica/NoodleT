# NoodleT

Простой торрент-клиент для Windows. Загрузкой занимается
libtorrent-rasterbar 2.0 — библиотека, на которой построен qBittorrent, с теми
же сетевыми настройками (DHT, PEX, LSD, UPnP/NAT-PMP, шифрование, uTP, до 500
соединений).

## Установка

1. Скачайте `NoodleT-Setup-<версия>.exe` со страницы
   [Releases](https://github.com/Navnica/NoodleT/releases/latest).
2. Запустите и нажмите «Далее». Права администратора не нужны: NoodleT
   ставится для текущего пользователя. Ничего дополнительно устанавливать не
   нужно.

Если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее» →
«Выполнить в любом случае»: установщик пока не подписан.

Обновление — так же: новый установщик ставится поверх старой версии, загрузки
и настройки сохраняются. Удаление — через «Параметры → Приложения».

## Открытие .torrent и magnet-ссылок

Установщик связывает NoodleT с `.torrent`-файлами и `magnet:`-ссылками
(галочку можно снять при установке). После этого торрент добавляется двойным
кликом по файлу в Проводнике или кликом по magnet-ссылке в браузере — в том
числе когда NoodleT уже открыт.

Если на компьютере уже есть другой торрент-клиент, Windows при первом открытии
спросит, чем открывать такие файлы: выберите NoodleT и «Всегда». Поменять выбор
можно в «Параметры → Приложения → Приложения по умолчанию → NoodleT».

## Возможности

- **`.torrent`-файлы** — двойной клик в Проводнике, кнопка со скрепкой или
  перетаскивание в окно.
- **Magnet-ссылки** — клик по ссылке в браузере, поле в панели сверху или
  просто Ctrl+V в окне. Кнопка рядом с пустым полем вставляет ссылку из
  буфера обмена.
- **Список загрузок** — у каждого торрента своя карточка, цвет показывает
  состояние: синий — загружается, ментоловый — скачан, фиолетовый — проверка
  или получение метаданных, серый — пауза, красный — ошибка.
- **Поиск, фильтр и сортировка** — над списком: поиск по имени (Ctrl+F),
  фильтр по состоянию, порядок по дате, имени, прогрессу, размеру или
  скорости. Там же кнопки «Остановить все» и «Запустить все». Правый клик по
  торренту — меню: пауза, показать в папке, удалить.
- **Подробности** — клик по карточке открывает панель справа: размер, загружено
  и отдано, рейтинг, скорости, оставшееся время, пиры и сиды, папка, хеш. Там
  же трекеры (можно добавить свои), список подключённых пиров, перенос в
  другую папку и «Качать по порядку» — чтобы смотреть видео, не дожидаясь
  конца загрузки.
- **Выбор файлов** — если в торренте больше одного файла, при добавлении
  открывается их список с галочками и выбор папки: снятые файлы не
  скачиваются. У magnet-ссылки список появляется, как только станут известны
  её файлы. Потом выбор можно поменять в панели подробностей.
- **Настройки** — папка для загрузок, лимиты скорости загрузки и отдачи, порт
  для входящих соединений (с подсказкой, доступен ли он извне), раздавать ли
  после загрузки, язык интерфейса (русский, английский или как в системе),
  проверка обновлений.
- **Работа в фоне** — крестик сворачивает окно в трей, загрузки продолжаются.
  Подсказка значка показывает текущие скорости, клик по нему открывает окно;
  в его меню — остановить или запустить все торренты и выход. Отключается в
  настройках.
- **Обновления** — при запуске NoodleT проверяет на GitHub, не вышла ли новая
  версия, и предлагает её скачать. Отключается в настройках.
- **Докачка** — список и прогресс сохраняются между запусками.
- Светлая и тёмная тема по системной.

## Где NoodleT хранит данные

Настройки и список торрентов лежат в `%APPDATA%\org.noodlet\noodlet`. При
удалении программы они остаются, и после повторной установки загрузки
продолжатся.

Переменная окружения `NOODLET_DATA_DIR` переносит эти данные в другую папку —
например, для отдельной независимой копии.

## Известные ограничения

- Готовых сборок для Linux и macOS пока нет.
