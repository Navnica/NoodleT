# NoodleT

Простой торрент-клиент для Windows, Linux и macOS. Интерфейс написан на
Flutter, загрузкой занимается libtorrent-rasterbar 2.0.11 — библиотека, на
которой построен qBittorrent, с теми же сетевыми настройками (DHT, PEX, LSD,
UPnP/NAT-PMP, шифрование, uTP, до 500 соединений).

## Возможности

- **`.torrent`-файлы** — кнопка со скрепкой, перетаскивание в окно или путь в
  аргументах командной строки.
- **Magnet-ссылки** — поле в нижней панели или просто Ctrl+V в окне. Круглая
  кнопка при пустом поле вставляет ссылку из буфера обмена.
- **Список загрузок** — у каждого торрента своя карточка, цвет показывает
  состояние: синий — загружается, ментоловый — скачан, фиолетовый — проверка
  или получение метаданных, серый — пауза, красный — ошибка.
- **Подробности** — клик по карточке открывает снизу панель: размер, загружено
  и отдано, рейтинг, скорости, оставшееся время, пиры и сиды, папка, хеш.
- **Настройки** — папка для загрузок, лимиты скорости загрузки и отдачи,
  раздавать ли после загрузки, язык интерфейса (русский, английский или как в
  системе).
- **Докачка** — список и прогресс сохраняются между запусками.
- Светлая и тёмная тема по системной.

## Сборка

Нужны [Flutter](https://docs.flutter.dev/get-started/install) 3.47 и то, что
он требует для настольных приложений:

| Система | Что установить |
|---------|----------------|
| Windows | Visual Studio с компонентом «Разработка классических приложений на C++» |
| Linux   | `sudo apt install clang cmake ninja-build pkg-config libgtk-3-dev` |
| macOS   | Xcode |

```sh
flutter pub get
flutter build windows --release   # build\windows\x64\runner\Release\noodlet.exe
flutter build linux --release     # build/linux/x64/release/bundle/noodlet
flutter build macos --release     # build/macos/Build/Products/Release/noodlet.app
```

Собирать нужно на той системе, под которую сборка. Проверена только сборка
под Windows.

На что можно наткнуться:

- **Запущенное приложение мешает сборке** — `noodlet.exe` занят. Закройте
  NoodleT и подождите несколько секунд: после закрытия окна процесс ещё
  досохраняет загрузки.
- **«File modified during build»** при первой сборке — пакет движка докачивал
  свою библиотеку. Запустите ту же команду ещё раз.
- **Пустое место вместо новой иконки интерфейса** — обычная пересборка не
  обновляет шрифт с иконками. Помогает `flutter clean` перед сборкой.

Для разработки: `flutter run -d windows`.

### Перенос на другой компьютер

Переносить нужно всю папку `Release` целиком, а не один exe. На Windows
приложению нужен Microsoft Visual C++ Redistributable 2015–2022 (x64) — он
обычно уже установлен; если нет, при запуске будет ошибка про
`VCRUNTIME140.dll`.

## Движок

libtorrent подключён готовым пакетом
[libtorrent_dart](https://pub.dev/packages/libtorrent_dart). Компилировать
libtorrent не нужно: при первой сборке пакет скачивает готовую библиотеку под
нужную систему из
[релизов своего репозитория](https://github.com/SenZmaKi/libtorrent_dart/releases)
(около 8 МБ), и Flutter кладёт её рядом с приложением.

Что стоит знать:

- Версия пакета в `pubspec.yaml` закреплена намеренно. У пакета нет имён для
  большинства настроек libtorrent, поэтому `lib/engine/engine.dart` задаёт их
  по номерам из libtorrent 2.0; при обновлении пакета номера нужно
  перепроверить.
- Библиотека скачивается без проверки контрольной суммы, из репозитория автора
  пакета.

## Данные приложения

Настройки и служебные файлы движка лежат в папке данных приложения:

| Система | Папка |
|---------|-------|
| Windows | `%APPDATA%\org.noodlet\noodlet` |
| Linux   | `~/.local/share/org.noodlet.noodlet` |
| macOS   | `~/Library/Application Support/org.noodlet.noodlet` |

| Файл | Что в нём |
|------|-----------|
| `settings.json` | настройки |
| `torrents.json` | список торрентов |
| `resume/<хеш>.resume` | состояние каждого торрента для докачки |
| `session.dat` | состояние сессии, в первую очередь узлы DHT |

Переменная окружения `NOODLET_DATA_DIR` переносит всё это в другую папку —
удобно для переносной копии или чтобы попробовать сборку, не трогая настоящие
загрузки.

## Переводы

Тексты интерфейса лежат в `lib/l10n/app_en.arb` (шаблон) и `app_ru.arb`. Из
них `flutter gen-l10n` генерирует `lib/l10n/app_localizations*.dart`; команда
сама запускается при `flutter pub get` и при каждой сборке, поэтому
сгенерированные файлы в репозиторий не входят.

Чтобы добавить язык:

1. создать `lib/l10n/app_<код>.arb` с теми же ключами;
2. добавить значение в `AppLanguage` в `lib/settings.dart`;
3. добавить кнопку в переключатель языка в `lib/ui/dialogs.dart`.

```sh
flutter test
```

Тесты движка поднимают настоящую сессию libtorrent, но в сеть не ходят.

## Иконка

Исходник иконки — `assets/icon/icon.png` (1024×1024). Файлы иконок для
Windows и macOS генерирует из него пакет
[flutter_launcher_icons](https://pub.dev/packages/flutter_launcher_icons),
настройки — в `flutter_launcher_icons.yaml`. После замены картинки:

```sh
dart run flutter_launcher_icons
```

Linux пакет не поддерживает, поэтому там `linux/CMakeLists.txt` кладёт в
сборку сам исходник, и он назначается окну. На Wayland (GNOME) иконку окна
система не показывает: она берётся из `.desktop`-файла установленного
приложения, которого в проекте нет.

Сгенерированные файлы (`windows/runner/resources/app_icon.ico` и PNG в
`macos/Runner/Assets.xcassets/AppIcon.appiconset`) хранятся в репозитории:
сборке они нужны, а сама она генератор не запускает.

## Устройство

| Путь | Что там |
|------|---------|
| `lib/main.dart` | запуск, язык и тема приложения |
| `lib/app_controller.dart` | состояние приложения, опрос движка раз в секунду |
| `lib/engine/engine.dart` | `TorrentEngine`: сессия libtorrent, список торрентов, resume-данные |
| `lib/settings.dart` | настройки и их хранение |
| `lib/input.dart` | разбор magnet-ссылок, хешей и путей к `.torrent` |
| `lib/notice.dart` | события, о которых сообщается пользователю |
| `lib/l10n/` | переводы (`.arb`); настройки генерации — в `l10n.yaml` |
| `lib/ui/` | интерфейс: главный экран, карточка торрента, панель подробностей, диалоги, тема |
| `windows/`, `linux/`, `macos/` | платформенные обёртки Flutter |
| `assets/icon/icon.png` | исходник иконки приложения |
| `flutter_launcher_icons.yaml` | настройки генерации иконок |
| `test/` | тесты движка, разбора ввода, форматирования и виджетов |

## Известные ограничения

Всё перечисленное ниже — известные недоработки, они будут исправлены в
следующих версиях.

- Привязки `.torrent`-файлов и `magnet:`-ссылок к приложению в системе нет:
  для этого нужен установщик.
- Windows: если приложение уже открыто, повторный запуск только выводит его
  окно вперёд; файл или ссылка из аргументов второго запуска не добавляются.
- Linux и macOS: окно при закрытии ждёт несколько секунд, пока сохранятся
  загрузки (на Windows оно исчезает сразу).
- Linux: у приложения, запущенного из папки сборки, на Wayland нет своей
  иконки в доке, а у исполняемого файла её нет ни в каком окружении.
- Нельзя выбрать отдельные файлы внутри торрента — скачивается всё.
